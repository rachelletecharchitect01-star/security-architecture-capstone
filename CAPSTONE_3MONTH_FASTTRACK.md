# Three-Month Capstone Fast Track

## Objective

Complete a defensible, reproducible MSBA capstone that estimates the economic value of a defined security-architecture investment using qualified public evidence and transparent assumptions.

## Month 1 — Scope and evidence

### Week 1: Lock the decision problem

- Define the security-architecture investment or comparison.
- Identify the decision-maker and the decision the analysis supports.
- Finalize the primary research question and supporting questions.
- Define the unit of analysis, time horizon, perspective, and primary outcomes.
- Record exclusions and feasibility constraints.

**Exit criterion:** A one-page approved study scope with no unresolved core design choices.

### Week 2: Build the evidence base

- Conduct a structured literature and public-data search.
- Populate the source inventory and literature matrix.
- Separate empirical observations, literature-derived parameters, and assumptions.
- Screen sources for authority, relevance, recency, granularity, accessibility, and licensing.

**Exit criterion:** A documented shortlist of usable sources and a source gap list.

### Week 3: Qualify the data

- Download and preserve raw files.
- Record source URL, publisher, access date, coverage, unit, and license.
- Profile missingness, duplicates, inconsistent definitions, and temporal coverage.
- Decide whether the proposed unit of analysis is supported.

**Exit criterion:** Data qualification memo with GO, CONDITIONAL GO, or NO-GO recommendation.

### Week 4: Finalize methods

- Specify equations, transformations, scenarios, and uncertainty treatment.
- Define baseline and alternative cases.
- Predefine sensitivity ranges and validation checks.
- Complete the variable dictionary and assumption register.

**Exit criterion:** Methods outline and analysis plan ready for faculty review.

## Month 2 — Analysis and interpretation

### Week 5: Build the analysis-ready dataset

- Create scripted cleaning and transformation steps.
- Preserve traceability from processed variables to raw sources.
- Generate descriptive tables and quality diagnostics.

### Week 6: Implement the baseline model

- Estimate baseline expected loss.
- Add investment costs and residual-risk assumptions.
- Calculate annual benefit, ROI, NPV, and payback period.
- Add automated validation checks.

### Week 7: Analyze uncertainty

- Run low, base, and high scenarios.
- Conduct one-way sensitivity analysis.
- Add Monte Carlo simulation only when defensible input distributions can be specified.
- Identify break-even thresholds.

### Week 8: Validate and interpret

- Reconcile outputs to source totals where possible.
- Test extreme and boundary cases.
- Review whether conclusions exceed the evidence.
- Draft results and limitations.

**Month 2 exit criterion:** Frozen analysis version with reproducible tables and figures.

## Month 3 — Paper, defense, and final quality

### Week 9: Draft the manuscript

Complete introduction, literature review, methods, results, and discussion using the paper outline.

### Week 10: Build the defense deck

Create an executive narrative: problem, decision, evidence, method, findings, uncertainty, recommendation, and limitations.

### Week 11: Review and revise

- Verify every quantitative claim.
- Complete citations and appendices.
- Run reproducibility checks from a clean environment.
- Incorporate faculty feedback.

### Week 12: Finalize

- Freeze the submitted data and analysis version.
- Proofread the paper and deck.
- Confirm repository documentation and file paths.
- Practice the defense and prepare questions.

## Weekly operating rhythm

- **Monday:** Define the week’s deliverable.
- **Midweek:** Run a quality and scope check.
- **Friday:** Commit completed work and update the decision log.
- **Weekend buffer:** Resolve only items that block the next milestone.

## Scope-control rule

Any proposed addition must replace an existing task, fit within the current milestone, or be deferred to future research.
