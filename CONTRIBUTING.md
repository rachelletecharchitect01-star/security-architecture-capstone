# Contributing and Research Workflow

## Branches and commits

- Use short, descriptive branches for substantive changes.
- Keep commits focused and use messages that describe the research change.
- Do not commit credentials, confidential data, or restricted security information.

## Data changes

- Add each source to the source inventory before analysis.
- Preserve raw source files unchanged.
- Generate processed data with documented code.
- Update the variable dictionary and assumption register when inputs change.

## Analysis changes

- Add validation checks with new calculations.
- Separate exploratory work from reported results.
- Record decision-relevant methodological changes in the decision log.
- Re-run the complete workflow before using new outputs in the paper or deck.

## Writing changes

- Cite quantitative and factual claims.
- Distinguish empirical results from assumptions and recommendations.
- Keep the paper, deck, appendices, and repository consistent.
